# Canvas learning fixtures

All records are invented offline fixtures on reserved example domains. The marker
`SYNTHETIC_DO_NOT_PERSIST` is invented test data identifying excluded fields, HTML
attributes, signed URLs or script/style content; it is not a credential.

These fixtures cover Classic Quizzes metadata, authorized discussion views, self
submissions, assignment groups and self enrollments/grades. They do not model New
Quizzes/LTI, attempts, answers, submission writes, grading or read-state mutations.

API contracts: [Quizzes](https://developerdocs.instructure.com/services/canvas/resources/quizzes),
[Discussion Topics](https://developerdocs.instructure.com/services/canvas/resources/discussion_topics),
[Submissions](https://developerdocs.instructure.com/services/canvas/resources/submissions),
[Assignment Groups](https://developerdocs.instructure.com/services/canvas/resources/assignment_groups),
[Enrollments](https://developerdocs.instructure.com/services/canvas/resources/enrollments).
