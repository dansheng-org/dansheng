# 旦生 Android 0.2.1 工作台

本页保留 0.2.1 的验收结果。新版 eHall 见 [0.2.2 使用和验收说明](ehall-0.2.2.md)。

这一版打开的是 eHall。校园办公、学习、搜索和论坛都不以安装插件为前提。手机使用 `dansheng-android-arm64-beta.apk`；在模拟器上可使用 `dansheng-android-x86_64-debug.apk`。只有需要定时预约时才导入独立的 `official.fudan-sports-0.2.0.dspack`。

| 入口 | 使用方式 |
| --- | --- |
| eHall | 从校园卡、教室、宿舍电量和场馆卡片进入。场馆余量按日期、时段和具体场地读取；没有成功读取时不显示虚构的可预约数量。手动预约和取消都需要核对具体记录。校园邮箱只保留入口。 |
| eLearning | 在日历上选日期，下方显示课程、到期作业和个人日程。选择课程可看公告、文件夹和资料；PDF、图片与文本可以在设备上阅读。教务与 Canvas 分别登录。 |
| Agent | 搜索本地记录，查看资料问答及出处；让外部 AI 客户端连接时才开启回环 MCP 服务。令牌仅在主动配对时提供，账号切换会关闭服务。这里的本地资料问答不冒充远程大模型回复。 |
| 论坛 | 支持全站／分区、置顶、排序、搜索、树洞详情、楼层、发帖和回帖。写入结果不确定时先核对，不会自动补发。 |
| 插件 | 目前提供定时抢场。系统选择文件后，应用用 Material 3 底部面板展示扩展来源与能力；新安装默认关闭。启用后，场馆页才显示定时入口。 |

**参考安排。** 服务卡片参考 DanXi 的 `feature_map.dart` 和 dashboard；课表参考本科／研究生课表入口；论坛参考 `subpage_forum.dart` 和 `forum_repository.dart` 的分区与楼层；场馆参考 `sports_reserve_repository.dart` 和 `sports_reservation.dart` 的页面请求与逐场可用条件。DanXi 检出仅作只读参考。

**账号与凭据。** 统一认证、树洞、Canvas 分别完成验证后才用 Android Keystore 加密保存。校园服务共用同一账号的统一认证密码，树洞邮箱／密码和 Canvas 令牌分开保存。退出会删除当前账号凭据、会话和后续定时任务。本机凭据文件不打入 APK；需要 MFA 时须由用户完成。

**DanXi 对照。** 单个任务按时段、候选场地顺序尝试；原生提前预热，放号前 60 秒读取场次，放号后 300 毫秒开始，在 5 分钟窗口内执行。只有明确拒绝才尝试候补；结果不明时先核对预约记录。后台仅已绑定且摘要核验的官方包可以请求恢复当前账号的体育页面，身份必须在预约站页面验证。另修正了树洞分页、课程级访问限制、教室楼号及宿舍电量更新时间可为空的情况。

**验收范围。** 离线设备测试涵盖模拟预约／取消与权限边界、定时插件、MCP 和个人日程／课程阅读。真实账号测试在独立 API 36 模拟器上完成，覆盖首次登录、强制结束进程后不再提供密码和退出清理。发布目录的 `CAMPUS-READONLY.json` 记录各项真实读取的状态及条数，与所测 APK 的 SHA-256 绑定，不含账号、金额、帖子或课件。课程资料权限按课程判断。

**构建和测试。** Flutter 静态分析、73 个 Flutter 测试和 77 个场馆 JS 用例通过。签名、APK 内容、原生库及设备阶段见 `BUILD-INFO.json`，文件摘要见 `SHA256SUMS`。ARM64 内测包已构建；未在 ARM64 真机测试厂商后台唤醒。没有向学校发起真实预约、取消、论坛发帖或邮件发送。

| 实际学校服务 | 这次在 Android 上观察到的结果 |
| --- | --- |
| 校园办公 | 校园卡余额、宿舍电量、校车和图书馆可读。通过学校 WebVPN 读取 28 间教室的容量和空闲节次。 |
| 树洞 | 已读到 5 个分区、帖子和楼层。强制结束进程后无需再输入论坛密码。 |
| Canvas | 原令牌被拒后，统一认证成功恢复。读取 13 门课程、作业、公告；一个开放资料的课程列出 19 个文件，并成功下载和读取一份实际课件。两个受限课程的文件列表返回课程权限不足。 |
| 教务与食堂 | 教务认证成功，但本科课表首页返回 HTTP 500；食堂登录要求交互验证。 |
| 体育 | 合成页面通过了不打开界面的冷启动身份恢复、模拟手动与定时预约。真实体育页面的后台身份核验超时，没有验证真实预约成功。 |
