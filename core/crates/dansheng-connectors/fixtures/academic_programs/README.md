# Public program fixtures

All records, names, dates, identifiers and content are invented. JSON shapes were
derived from public protocol observations, not copied from a live response. The
`SYNTHETIC_EXCLUDED` marker is invented data for sanitizer/exclusion tests.

The fixtures model a public program's requirements, paragraph text and bounded
course-module projection. They contain no student's progress, credentials, actual
school response, original page or downloaded document. Artificial HTML snippets
exercise inert text handling and removal of attributes/script/style content.

Only anonymous GET list/detail is supported. Public form filters, authenticated
real-info, Word export, selection and personal credit certification are excluded.
